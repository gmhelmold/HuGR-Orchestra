# [P2] OWN-002 — Validar check.kind junto ao corpo do predicate

Status: preparado, **não publicado como issue** (HTTP 410). Base: `b0c33d2f6567a2c741240f3c44bc00ca2f01e7e7`.
Evidência: contrato original e scripts originais executados com Git real e digest kernel de teste.

## Observação e impacto

Para predicate, `isFact()` exige check com expr OU query string, mas não valida o discriminante. `claimOf()` seleciona `check.kind === 'assertion' ? check.expr : check.query`. Com expr e sem kind, o snapshot é aceito e o corpo sai literalmente como `undefined`. Assertion com apenas query e index-query com apenas expr têm a mesma inconsistência.

Um item governing malformado chega a uma skill verificada. Não se afirma que todo produtor tipado interno gere a forma inválida; a fronteira afetada recebe JSON.

## Reprodução e double check

Gotcha `{id:'bad-check',kind:'predicate',tier:'T1',freshness:'FRESH',check:{expr:'value === 1'}}`. Parser e exportador aceitam, renderer imprime undefined, materializador e guard originais encerram com exit 0 em fixture Git real. Controles com assertion+expr e index-query+query renderizam corretamente; fonte alterada e fato stale são recusados.

A substituição de `@atlas/kernel.id` não está oculta: o teste não valida a identidade real BLAKE3. Git, blobs e scripts foram reais e as fontes tiveram identidade Git conferida.

## Correção proposta

Validador discriminado: assertion requer expr; index-query requer query; outras variantes só com contrato explícito. Não mascarar o defeito no renderer com string vazia ou fallback silencioso.

## Completeness criteria

Kind ausente/desconhecido, corpo da variante errada, nulo/escalar, variantes válidas; parser, exportador, materializador e guard; recusa antes de instalação.

## Success criteria

Nenhum snapshot validado renderiza corpo undefined por falta de campo obrigatório. Inputs válidos continuam determinísticos.

## Quality standards

Fixtures JSON de fronteira e execução dos scripts; exigir motivo de recusa específico; não usar apenas typecheck de objetos já tipados.

## Definition of done

Regressões negativas e positivas passam no ambiente oficial sem substituir kernel; instalação anterior preservada em recusa; comandos e saídas anexados.

## Invariants

Discriminante e corpo concordam; JSON não recebe confiança dos tipos estáticos; ausência de corpo não vira fato governing vazio.
